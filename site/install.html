Install.

Kinescript is a Python package with a command, kine. It needs Python 3.10 or newer and ffmpeg.

terminal
pip install kinescript
kine doctor

Needs Python 3.10 or newer and ffmpeg on your PATH. kine doctor prints the ffmpeg path, whether a GPU context opened, and the default font. Space Grotesk and IBM Plex Mono ship with the package, so default text looks the same on every machine. For voice-over from text, add a voice plugin: kinescript-kokoro, kinescript-chatterbox or kinescript-elevenlabs.

a first scene
kine new scene.json
kine check scene.json
kine look scene.json --boxes
kine render scene.json -o scene.mp4

More scenes in examples/. The README covers every feature and the limits.

Every command

kine <command> --help lists each one's options. The MCP tools on the Agents page call the same code.

  • kine newwrites a starter scene
  • kine docsprints the scene reference, written to fit in a model's context
  • kine checklayout, timing, contrast, reading time and sound problems, as JSON
  • kine looka contact sheet of many frames, with --boxes, --trails, --onion, --audio, --wire or --depth drawn over it
  • kine watchmakes the contact sheet again each time the scene file is saved
  • kine stillone frame to PNG or JPG; --at poster saves the frame a video opens on
  • kine probethe resolved timeline and every layer's box at a time; --curve title.x a key's value at every frame; for a media file, its length, size, fps and audio
  • kine renderthe video, a frame range, or the sound alone
  • kine voicespeaks each sound's text into its file and times its words
  • kine editopens the scene in the browser editor
  • kine brandmakes, shows, changes and uses brands, and opens the brand wizard
  • kine mcpthe MCP server, on stdio
  • kine doctorreports ffmpeg, the GPU and the default font

kine render

The extension picks the format: .mp4, .mov, .webm, .gif, a .png sequence, or the sound alone as .wav, .m4a, .mp3 or .flac. Frames render in parallel processes and are encoded in chunks.

terminal
# a fast preview
kine render scene.json -o draft.mp4 -q draft --scale 0.5
# one stretch of it
kine render scene.json -o part.mp4 --from 4 --to 9
# no background, for compositing
kine render scene.json -o title.webm --transparent
# the sound alone
kine render scene.json -o mix.wav
# the frame it opens on, for a page's <video poster>
kine still scene.json --at poster -o poster.jpg

canvas.poster names the time a rendered video opens on, so a player shows a real frame before it plays; kine check warns when frame 0 is blank and no poster is set. -j sets the number of render processes.
