# making-kinescript-videos

A copy of the agent skill for writing, voicing, checking and rendering Kinescript scenes. To use it with Claude Code,
copy this folder to `.claude/skills/` (in a project) or `~/.claude/skills/`; other agents can read `SKILL.md` directly.

The canonical version lives in
[oaustegard/claude-skills](https://github.com/oaustegard/claude-skills/tree/main/making-kinescript-videos). Edit it
there; this copy is refreshed from it and may lag behind.
